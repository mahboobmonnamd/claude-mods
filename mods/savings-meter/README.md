# savings-meter

Reads ~/.claude/token-mods/ledger.jsonl and reports tokens saved this chat, today and all time, by plugin. A route whose file was read again afterwards is taken back. Token counts are estimates.

Command: `/savings`

## Install

```
/plugin marketplace add mahboobmonnamd/claude-mods
/plugin install savings-meter@claude-mods
```

Part of the Lean pack; see the repo README.
