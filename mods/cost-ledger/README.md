# cost-ledger

A side pane over the Lean pack's ledger: this chat, today and all time, by plugin, plus the latest actions. Savings are net of re-reads and shown with helper-model cost. Needs a wide terminal; `/savings` prints the same figures as text.

Command: `/cost-ledger`

## Install

```
/plugin marketplace add mahboobmonnamd/claude-mods
/plugin install cost-ledger@claude-mods
```

Part of the Lean pack; see the repo README.
