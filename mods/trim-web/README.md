# trim-web

Web search and fetch results over 3,000 tokens are shortened by Haiku to findings plus sources and dates. Fails open: the original stays unless the saving is real.

Command: `/trim-web`

## Install

```
/plugin marketplace add mahboobmonnamd/claude-mods
/plugin install trim-web@claude-mods
```

Part of the Lean pack; see the repo README.
