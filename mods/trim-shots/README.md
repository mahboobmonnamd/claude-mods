# trim-shots

Screenshots from browser tools are cut to 1024 px on the long side with macOS sips. `full` lets the next one through whole. macOS only.

Command: `/trim-shots, /trim-shots full`

## Install

```
/plugin marketplace add mahboobmonnamd/claude-mods
/plugin install trim-shots@claude-mods
```

Part of the token-saving pack; see the repo README.
